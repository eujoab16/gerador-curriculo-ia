# 🤖 Construtor Inteligente de Currículo

Um assistente interativo em formato de chat desenvolvido para ajudar usuários a criarem currículos profissionais e modernos de forma simples, rápida e totalmente otimizada para dispositivos móveis (smartphones) e computadores.

🌐 **Acesse o projeto online:** [https://eujoab16.github.io/gerador-curriculo-ia/](https://eujoab16.github.io/gerador-curriculo-ia/)

---

## ✨ Funcionalidades Principais

* **Assistente de Chat Intuitivo:** Fluxo conversacional amigável que coleta dados passo a passo (Dados Pessoais, Objetivo, Formação Acadêmica, Experiência Profissional e Habilidades).
* **Validação e Correção Automática:** 
  * Capitalização correta de nomes, endereços e títulos.
  * Formatação automática de telefones (com DDD) e e-mails.
  * Filtros inteligentes para evitar números em nomes próprios.
* **Geração de PDF Instantânea:** Utiliza a biblioteca `jsPDF` para montar um layout corporativo limpo, elegante e pronto para download diretamente no navegador.
* **Personalização Visual:**
  * Escolha de cores de destaque para o currículo (Verde Petróleo, Azul Escuro, Vermelho, Cinza Executivo, Roxo Elegante).
  * Suporte opcional para envio de foto de perfil.
* **Acessibilidade Completa:**
  * Modo de Alto Contraste para melhor legibilidade.
  * Botões de controle para aumentar ou diminuir o tamanho da fonte (`A+` / `A-`).
  * Design totalmente responsivo adaptado para celulares com suporte a áreas seguras (*safe-area-inset*).
* **Navegação Inteligente:** Botão de "Voltar e corrigir anterior" em cada etapa caso o usuário queira alterar alguma informação informada anteriormente.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5 / CSS3:** Estrutura moderna com variáveis CSS (`:root`), flexbox e design responsivo.
* **JavaScript (Vanilla):** Lógica do chatbot, manipulação de DOM e validações de dados em tempo real.
* **jsPDF (v2.5.1):** Biblioteca em JavaScript para criação dinâmica de documentos PDF no lado do cliente.

---

## 🚀 Como Executar o Projeto Localmente

Como este projeto é construído em um único arquivo HTML contendo todo o CSS e JavaScript embutidos, executá-lo é extremamente simples:

1. Clone ou faça o download deste repositório.
2. Certifique-se de que o arquivo principal se chama `index.html`.
3. Dê dois cliques no arquivo `index.html` para abri-lo em qualquer navegador web moderno (Google Chrome, Microsoft Edge, Safari, Firefox).
